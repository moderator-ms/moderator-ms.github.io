Sanvee's Moderator Management System

How to use:
1. Extract the ZIP.
2. Open index.html in Chrome/Edge.
3. Log in with the configured admin credentials.
4. Use the Dashboard, Attendance, Moderators, Leave, Reports, and Config panels from the navigation.

Features:
- Modern professional UI with responsive dashboard cards, modal detail views, and refined controls.
- Login screen with configurable credentials (default: manik@gmail.com / @Manik1243).
- Config panel to update login email and password.
- Dashboard sections for total moderators, present, weekly off, on leave, absent, night shift, and outside duty.
- Moderator management with salary and weekday editing, plus Night Shift and Outside Duty assignment.
- Leave management with date ranges and reason notes.
- Report generation for date ranges with types: All, Attendance, Leave, Night Shift, and Outside Duty.
- Print-friendly report output.

Data persistence:
- LocalStorage stores moderators, leave records, special assignments, and configuration.
- Supabase integration remains available if valid credentials and database tables are configured.
