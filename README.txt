Sanvee's Moderator Management System

How to use:
1. Extract the ZIP.
2. Open index.html in Chrome/Edge.
3. Attendance, leave and moderator changes are stored in this browser using localStorage.

Important:
This is the standalone first version. Data is stored on the device/browser where it is entered.
For multi-device/cloud access, authentication and central database, connect a backend/database in the next deployment stage.
